# Ukraine Air Defense (UAD)

3D-игра о ночном дежурстве ПВО над Киевом, Харьковом, Днепром и Одессой. Движок — **Godot 4.7.2** (GDScript, рендер *GL Compatibility*),
собирается в Windows `.exe`, Android `.apk` и `.aab` из одного проекта.

**Все ресурсы процедурные**: здания, река, лес, техника, ракеты, небо со звёздами, UI-тема, шрифты (системные),
даже звуки (сирена, взрывы, выстрелы) синтезируются в коде. Из файлов — только иконка и музыка.

**Скачать**: https://mikeliashenko.github.io/UAD/ — Windows `.exe` и Android `.apk` последней сборки.

## Быстрая сборка

```bat
build.bat            :: -> build\windows\UAD.exe
build.bat apk        :: -> build\android\UAD.apk
build.bat aab        :: -> build\android\UAD.aab
build.bat all        :: .exe и .apk
build.bat all -Publish   :: собрать и выпустить: релиз на GitHub + предложение обновиться в играх
```

`build.ps1` сам:
1. находит Godot 4.7.2 в `tools\` (или `%GODOT%`), при отсутствии скачивает с GitHub (~82 МБ);
2. ставит шаблоны экспорта в `%APPDATA%\Godot\export_templates\4.7.2.stable` (из `tools\templates.tpz`, при отсутствии скачивает ~1.2 ГБ);
3. ставит **номер сборки** (см. ниже) в `scripts/build_info.gd` и `export_presets.cfg`;
4. делает `--import` и `--export-release` нужного пресета из `export_presets.cfg`.

Ключи: `-NoBump` — пересобрать без нового номера, `-DebugBuild` — отладочная сборка,
`-Notes "..."` — что нового (видно в игре и на сайте).

### Android (.apk / .aab)
Шаблоны Android уже устанавливаются скриптом. Дополнительно нужны:
- **JDK 17** и **Android SDK** (Build-Tools, Platform-Tools) — пути указываются один раз в Godot: *Editor → Editor Settings → Export → Android*;
- ключ подписи релиза скрипт создаёт сам при первой сборке: `%USERPROFILE%\.uad\uad-release.keystore`
  и пароль в `signing.json` рядом. **Сохраните копию этой папки** — обновление, подписанное другим
  ключом, не встанет поверх установленной игры. Свой ключ можно задать переменными
  `GODOT_ANDROID_KEYSTORE_RELEASE_PATH` / `_USER` / `_PASSWORD`;
- для `.aab` (Google Play) — Gradle-сборка: один раз *Project → Install Android Build Template* в редакторе.

## Сборки и обновления

У каждой сборки есть номер: `scripts/build_info.gd` (`BUILD`, дата, коммит) — `build.ps1` увеличивает
его на 1 при каждой сборке и вписывает в версию файла `.exe` (`1.0.0.N`) и в `versionCode` Android.
Номер виден в главном меню («сборка N»).

`build.ps1 -Publish` выпускает сборку: коммит и `git push`, релиз `build-N` на GitHub с `UAD.exe` и
`UAD.apk` (нужен `gh`, один раз `gh auth login`), и запись о новейшей сборке в базу — `uad/release`
(номер, версия, дата, что нового, ссылки на файлы). Каждая игра при запуске читает `uad/release`;
если там номер больше своего, в главном меню появляется кнопка **«⬆ Доступна сборка N — обновить»** с
окном: что нового, «Скачать обновление» (на Windows — `.exe`, на Android — `.apk`), «Открыть сайт игры».
Ссылки из базы игра и сайт открывают только если они ведут на релизы этого репозитория — иначе сайт.

Правила базы (`firebase/database.rules.json`) запрещают запись в `uad/release` всем: выпускать сборки
может только владелец. Для этого положите секрет базы (*Firebase → Project settings → Service
accounts → Database secrets*) в `%USERPROFILE%\.uad\firebase_secret.txt` — `build.ps1` добавит его к записи.

## Сайт

`docs/index.html` — страница игры на GitHub Pages (https://mikeliashenko.github.io/UAD/, из папки
`/docs` ветки `main`): кнопки «Скачать для Windows / Android» (на телефоне первой идёт `.apk`),

## Миры (сохранения)

Как в Minecraft: **Играть → Главная**. Каждая оборона — отдельный мир в `user://saves/*.json`
(Windows: `%APPDATA%\Godot\app_userdata\Ukraine Air Defense (UAD)\saves`). Автосохранение — каждое утро
и при выходе днём; ночь не сохраняется (при выходе ночью продолжите с утра). Сохраняются бюджет,
купленные системы, ракеты, день, повреждённые крыши. После поражения — «Повторить с последнего утра».

## Мультиплеер

**Играть** — две вкладки: **Главная** (свои миры) и **Мультиплеер** (миры друзей).

- У каждого игрока есть **код друга** (`K7MQ-4XRT`, вкладка «Мультиплеер» → «Копировать»). Друга
  добавляют по коду; в списке видно, в сети ли он, в меню или в игре, и какой мир открыл
  (город, день, ночь/налёт, игроков 2/4, качество связи).
- Хост открывает мир в игре: **пауза → «Открыть для друзей»**. Друг жмёт «Запросить подключение»;
  у хоста всплывает карточка «Оля хочет присоединиться» — **Y** принять, **N** отклонить (30 с).
- Гость загружает город хоста и ставит свою базу на карте — базы остальных игроков уже видны.
- В игре видно друг друга: базы друзей с лучом их цвета и подписью, «глаз» — где сейчас камера
  друга и куда он смотрит (у орудия / FPV / над картой), ромбы на радаре.
- **Tab** — список игроков (ник, что делает, где база, пинг) и кнопка **«Смотреть»** — вид глазами
  друга (его прицел, пульт FPV); Esc или V — вернуться.
- В гостях ничего не сохраняется; «Отключиться» — в паузе. Если хост закрыл мир — экран «Отключено».

### Два способа: код или аккаунт

По умолчанию регистрации нет: игрок — это **код друга**, который хранится на устройстве. По желанию
можно завести **аккаунт** (вкладка «Мультиплеер» → «Регистрация»: ник, почта, пароль):
- текущий код, ник и друзья переходят в аккаунт — друзья, знающие код, ничего не теряют;
- друга можно добавить **по нику** (без учёта регистра), а не только по коду; игроки без аккаунта
  тоже могут найти по нику тех, у кого он есть;
- список друзей хранится в облаке: вошли на телефоне или другом ПК — там те же код, ник и друзья;
  друзья, добавленные на устройстве до входа, присоединяются к аккаунту;
- «Аккаунт» — сменить ник, выйти (вернётся код устройства), удалить аккаунт (по паролю: ник,
  облачный список и вход удаляются навсегда); «Забыли пароль?» присылает письмо со ссылкой.

Вход — Firebase Authentication (почта + пароль, `core/fb_auth.gd`): на устройстве хранится только
refresh-токен, никогда пароль; ID-токен обновляется за 5 минут до истечения и идёт с каждым запросом
(`?auth=`). В базе (`core/account.gd`): `accounts/<uid>` — профиль и друзья (читает и пишет только
владелец), `names/<ник>` — ник → код, `codes/<код>` — код принадлежит аккаунту, и правила не дают
никому другому писать присутствие, запросы и данные сессии под этим кодом.

Чтобы аккаунты заработали (без этого игра просто работает по кодам, кнопок аккаунта нет):
1. Firebase → **Authentication → Sign-in method → Email/Password → Enable**.
2. Firebase → Project settings → **Web API Key** → файл `scripts/keys.gd` (он в `.gitignore`, в
   сборку попадает):
   ```gdscript
   const FIREBASE_WEB_KEY := "AIza..."
   ```
3. Правила из `firebase/database.rules.json` → Realtime Database → Rules (ветку `uad` — рядом с
   правилами остальных данных базы).

Самотест без сети: `-- --acctest` (база в памяти и заглушка входа: регистрация, уникальность ника,
друзья по нику, вход/выход, смена ника, восстановление сессии, удаление, отозванная сессия);
`--accshow=out|in|login|register|manage|delete` — показать вкладку в этом состоянии.

### Общие налёты

Налёт один на всех: его ведёт игра хоста, у гостей в небе те же цели, в тех же местах.
- Хост 4 раза в секунду (раз в секунду, когда небо пустое) отправляет снимок налёта: фаза и часы
  дня/ночи, каждая цель — позиция, скорость, прочность, по какой базе идёт. Цели распределяются по
  базам всех игроков.
- Гость стреляет по «куклам» целей: урон уходит хосту, тот засчитывает сбитие и награду тому, кто
  попал (у гостя сбитие показывается сразу и откатывается, если хост его не подтвердил за 3 с).
- Обломки, пожары, обрушения, блэкауты — общие; ракеты друзей видны в небе. Штраф за упавшее на
  крыши и урон по базе — тому, чья цель/база; счёт каждого гостя ведёт хост.
- Сетевая игра не встаёт на паузу (пауза — только меню), замедление при сбитии выключено.

**Задержка и сглаживание.** Замер `node tools_scripts/fb_probe.js` (база в us-central1):
первый запрос с новым TLS — ~380 мс, запись по удерживаемому соединению — ~170 мс (≈6 записей в
секунду на соединение), запись → живой поток у другого игрока — ~180 мс. Поэтому игра держит два
постоянных HTTPS-соединения (`core/fb_conn.gd`: присутствие и налёт, частые записи одного ключа
схлопываются), а на гостях цели не прыгают от снимка к снимку: позиция экстраполируется по скорости
(с баллистикой) на возраст снимка по часам сервера, ошибка гасится экспоненциально (~0.2 с), камеры
друзей — так же с предсказанием по их скорости. В живом тесте: ~4 снимка/с, возраст ~190 мс,
средняя поправка позиции цели 1.5–3 м. Tab показывает пинг, снимков в секунду и их возраст.

Связь — Firebase Realtime Database (`Net.DB_URL`, данные в ветке `uad/v1`): REST для записей и
поток server-sent events для живых обновлений, без проброса портов. Правила доступа —
`firebase/database.rules.json` (вставить в консоли Firebase → Realtime Database → Rules, сохранив
правила для остальных данных базы). Авторизации нет: кто знает адрес базы, может писать в `uad/v1`.

## Города

При **создании мира** выбирается город — у каждого своя процедурная карта, районы, реки или море,
мосты, трассы, железная дорога, достопримечательности, направления налётов и свой канал нарезок.
Мир запоминает свой город; при запуске мира другого города карта перестраивается (экран «Загрузка карты»),
а главное меню показывает город последнего мира.

| Город | Вода | Особенности | Откуда налёты |
|---|---|---|---|
| **Киев** | Днепр, Русановская протока, Гавань, Десна, озёра левого берега | Труханов остров и Гидропарк, Жуков остров, Русановский канал; 8 мостов (Северный, Подольский, Гаванский, Пешеходный, Метро, Патона, Дарницкий, Южный) + ж/д мост; Лавра, Родина-мать, София, Майдан, Рада, Дворец спорта, «Салют», МВЦ, ВДНХ, вокзалы Центральный и Дарница | со всех сторон |
| **Харьков** | узкие Лопань, Харьков, Немышля, Уды, Журавлёвское водохранилище | Госпром и площадь Свободы, Каразинский университет, ОГА, Благовещенский и Успенский соборы, «Зеркальная струя», ХТЗ, Турбоатом, Малышева, Салтовка, Лесопарк и парк Горького с колесом обозрения; обломкам почти некуда падать | с севера и северо-востока |
| **Днепр** | самый широкий Днепр, Монастырский остров, Самара | длинная набережная, Центральный, Новый, Кайдацкий и Южный мосты, Амурский ж/д мост, «Парус», «Башни», «Менора», Преображенский собор, ДМЗ с домнами, Южмаш с ракетой, Приднепровская ТЭС | с востока и юга |
| **Одесса** | Чёрное море до горизонта, Куяльницкий и Хаджибейский лиманы | порт с кранами, контейнерный терминал, молы, Воронцовский маяк, Морвокзал и гостиница «Одесса», Потёмкинская лестница, Оперный театр, Спасо-Преображенский собор, Привоз, пляжи Лузановки, Ланжерона и Аркадии, НПЗ на Пересыпи | с моря |

Тип позиции «у воды» называется по городу: *Берег Днепра*, *Берег реки*, *Морское побережье*.

### Чем бьют по каждому городу

Состав налётов взят из реальных ударов (сводки Воздушных сил, открытые источники) и задаётся в
`CityDef.raid`: веса, первая ночь, направления пусков (`raid_sectors`), дополнительные пуски и события.
В сумерках в журнал приходит **сводка разведки**: какие средства ожидаются этой ночью.

| Город | Дроны | Крылатые / бомбы | Баллистика | Особенности |
|---|---|---|---|---|
| **Киев** | шахеды, ложные цели «Гербера» (без БЧ, приходят роями), реактивные «Герань-3» | Х-101 с Ту-95, «Калибр» с моря (с юга) | «Искандер-М», «Кинжал» Х-47М2 | «Кинжал» эффективно берёт только Patriot |
| **Харьков** | шахеды, «Молнии» (роями, низко), «Герань-3» | **КАБ с УМПК** — каждую ночь из-за границы, Х-101 | **С-300 по земле** (подлёт 8–10 с) с 3-й ночи, «Искандер-М» | всё летит с севера; против КАБ стволы почти бесполезны |
| **Днепр** | шахеды, «Герберы» | Х-101, «Калибр» | «Искандер-М» из-под Таганрога, **Х-22** | **ночь 10 — «Орешник» по Южмашу**: 6 боевых блоков с кинетическими суббоеприпасами, берёт только Patriot, и то редко |
| **Одесса** | шахеды и «Герберы» с моря, «Герань-3» | «Калибр» с кораблей, сверхзвуковой **«Оникс»** над самой водой | «Искандер-М», **Х-22** из Крыма | с 4-й ночи **Х-31П** охотятся за радаром вашей базы |

Новые цели — это варианты базовых моделей полёта (`kind`): у каждого свои скорость, высоты,
время баллистического полёта, прочность, разрушительность боевой части и сопротивление отдельным
системам ПВО (`eff_mult`, считается через `GS.eff()`). Своя 3D-модель у каждой: реактивный шахед с
турбиной, фанерная «Молния», КАБ с крыльями УМПК, «Оникс» с белым факелом, «Кинжал» в фиолетовой плазме,
раскалённый боевой блок «Орешника».

### Детализация карт

На «Высоком» качестве города наполнены деталями (на «Низком» они скрыты ради производительности):
лоджии с горящими окнами на панельках, фонари над подъездами, кондиционеры, антенны и баки на крышах,
угловые башенки со шпилями на сталинках, ступенчатые короны небоскрёбов, неоновые вывески на крышах и
светящиеся витрины в центре, тысячи припаркованных машин вдоль бордюров, деревья вдоль всех улиц,
детские площадки во дворах, газоны и мощение, зебры на каждом перекрёстке, светофоры на проспектах,
башенные краны над новостройками, дым из заводских труб, ЛЭП от ТЭЦ, рекламные щиты вдоль трасс,
суда у причалов и на рейде (контейнеровозы, зерновозы, баржи), зонтики на пляжах. Детали на зданиях
оседают и прячутся вместе с обрушенными этажами и возвращаются после восстановления.

**Что нового в карте Киева**: русло с протокой и настоящими островами (Труханов, Гидропарк, Жуков),
Гавань с Рыбальским полуостровом, Десна, озёра (Тельбин, Вырлица, Опечень…), 25 районов вместо 17,
10 трасс с разметкой, фонарями, машинами и пешеходами (Броварской, Победы, Бандеры, Голосеевский,
Окружная…), мосты на подходах с пандусами, железная дорога с поездами через Дарницкий ж/д мост,
периметральные кварталы с дворами в центре, новые достопримечательности, пляжи на островах.

### Графика: «Высокое» и «Ультра»

Качество — в настройках (на ПК по умолчанию «Ультра», на телефоне — «Высокое»); в шейдеры оно
приходит глобальной переменной `gfx` (0 — низкое, 1 — высокое, 2 — ультра).
- **Небо**: объёмные облака (FBM), подсвеченные снизу заревом города ночью и солнцем на закате,
  звёзды, Млечный Путь и луна; дымка у горизонта того же цвета, что туман, — город растворяется в ней.
- **За краем карты** — ландшафт до горизонта (на 20+ км во все стороны): поля, лесополосы и сёла,
  продолжения рек, трасс и железных дорог, выходящих с карты; ночью горят сёла, фонари и фары на трассах.
- **Окна** с интерьерами (interior mapping): за стеклом видны комнаты с глубиной, стенами, полом и
  потолочными лампами, мебель, шторы и жалюзи, переплёты рам; у каждой комнаты свой свет.
- **Вода**: плавные пересекающиеся волны, отражения неба, а на «Ультра» — экранные отражения
  (SSR) огней набережных, мостов и зданий, пена и отмели у берега.
- **Подсветка** памятников и мостов прожекторами снизу, световые шлейфы фар и стоп-сигналов на трассах.
- Тонмаппинг ACES, свечение (glow), свои экспозиция, насыщенность и туман для дня и ночи.

## Два вида

- **Вид сверху (V)** — тактическая карта: назначение целей кликом, прогноз падения обломков.
- **Вид с базы (V)** — прицел наводчика выбранной установки: мышь наводит, ЛКМ — огонь / пуск,
  ПКМ и колесо — зум, **N — ночной прицел**, Alt — свободный курсор. У Gepard/IRIS-T/Patriot есть
  СУО (точка упреждения, захват цели), у пикапа — только метки прицела, упреждение на глаз.
  Эффектные сбития: вспышка, огненный шар, ударное кольцо, «золотой дождь» обломков, падающий горящий
  корпус, звук взрыва с задержкой по дальности, замедление времени (отключается в настройках).

## Дроны-перехватчики «Шершень» и пульт FPV (C)

Пятая система ПВО — **рой дешёвых дронов-камикадзе** против «Шахедов» (крылатую ракету
берут две штуки, баллистику — никак). Пусковая установка стоит на базе и работает как ствольная:
при включённом **АВТО [F]** сама поднимает дроны по целям, либо цель назначается кликом из вида сверху,
либо пуск идёт из вида с базы (захват прицелом → ЛКМ).

- Дрон сам догоняет цель и **таранит** её; по дороге обходит крыши и высотки.
- Не нашёл работы — барражирует, потом **возвращается на базу**, и боекомплект восстанавливается:
  потрачены только те дроны, что сбили цель или разбились.
- Аккумулятор ~46 с: на исходе дрон уходит домой сам.
- Как и умный автоогонь, рой **предпочитает цели, обломки которых упадут не на дома**.
- **C — пульт FPV**: вы садитесь за видеолинк и ведёте дрон руками. Управление — как «мышиный
  прицел» в лётных играх: мышь/свайп двигает **кольцо** (куда лететь), дрон разворачивается к нему
  так быстро, как может, а центр экрана всегда показывает, куда он летит. W/S или колесо — тяга,
  A/D и стрелки — поворот с клавиатуры, Shift/ЛКМ — разгон, Пробел — следующий дрон в воздухе,
  R — отправить домой, N — ночная камера (включается сама настоящей ночью, с автоусилением — в
  сумерках не заливает экран), C/V/Esc — выйти с пульта.
- Наведение: цель, на которую вы смотрите, захватывается; **красный ромб** — точка встречи с ней
  (с упреждением), и вблизи кольцо мягко «прилипает» к ромбу; если цели нет в кадре, у края экрана
  **стрелка** с дальностью. Таран засчитывается по любой цели, в которую вы врезались.
- На экране: горизонт, угол набора/снижения, рамки целей с дальностью и сближением, заряд, тяга,
  высота, сигнал. Чем дальше от базы — тем сильнее **рябь и помехи**; за пределами линка (7.5 км)
  связь рвётся и дрон доделывает работу сам. Корпус дрона в кадре не виден, картинка не трясётся
  (кроме разгона и попаданий), в поворотах камера кренится.
- Дрон взорвался или разбился — секунда «НЕТ СИГНАЛА» с помехами, затем пульт берёт следующий дрон
  в воздухе (или возвращает прежний вид).
- Проверка без рук: `-- --autotest --weapons=drone --view=fpv --aimbot` — тестовый пилот ведёт
  кольцо не быстрее руки с мышью, в итоге — `fpv_flights / fpv_rams / fpv_crash / fpv_link_lost`.
- Утром все дроны из воздуха отзываются на базу, в отчёте — строка «Вылетов дронов · таранов».

## Удары по точкам пуска (K)

Ответный ход: днём можно бить по местам, откуда летят угрозы (`game/strikes.gd`, экран
`ui/strike_map.gd`). У каждого города свои точки пуска — по тому, чем его бьют, на пеленгах, откуда
реально приходят цели, и на своей дальности: пункт управления «Орланами», площадки шахедов,
аэродромы Ту-95МС / МиГ-31К / Ту-22М3 / Су-34 / Су-24, корабли с «Калибрами», «Бастион»,
«Искандеры», С-300. Сначала точка неизвестна — **разведка засекает её, когда оттуда прилетает первая
цель** (запись в журнале).

- **Оперативная карта**: город в центре, кольца дальности (шкала сжата, чтобы и 45 км, и 1000 км
  поместились), точки со значками по типу и состоянию, круги досягаемости наших средств, удары в
  полёте ползут к целям до заката.
- **Чем бить** (со второго дня, только днём): дальний дрон **«Лютый»** ($4 500, 1100 км — достаёт до
  стратегической авиации, чаще повреждает), ракета **«Нептун»** ($12 000, 400 км, бьёт и корабли),
  **Storm Shadow** ($21 000, 260 км, почти наверняка уничтожает). Шанс зависит от ПВО точки;
  после каждого удара противник её усиливает.
- **На закате** удары долетают: в журнале результат по каждому, крупно — «N из M в цель».
  **Повреждённая** точка запускает вдвое меньше (2 ночи), **уничтоженная** молчит (2–3 ночи), второй
  удар по повреждённой добивает её. Площадки шахедов при уничтожении оставляют ~30% пусков с
  запасных. Утром противник чинит точки («Противник восстановил: …»).
- Выбитый пункт разведки — меньше «Орланов» днём, база реже обнаруживается; выбитый аэродром Ту-95 —
  этой ночью нет Х-101; флот — нет «Калибров».
- В сетевой игре удары наносит хозяин мира (они меняют общий налёт).
- Проверка: `-- --striketest` (правила без игры, сохранение), `--sitesdown` (все точки выбиты — налёт
  сжимается), `--open=strikes --strikedemo` (карта со всеми состояниями).

## Лента города: нарезка ночи (T)

Каждую ночь горожане снимают перехваты с балконов, а утром канал города (**@kyiv_cuts**, **@kharkiv_cuts**,
**@dnipro_cuts**, **@odesa_cuts**) склеивает лучшее
в один ролик на 30 секунд — и его можно пересмотреть за любой день.

- Игра запоминает каждое сбитие: точку, курс цели, чем сбили, район и время ночи.
- Утром из них отбираются **шесть самых зрелищных** (баллистика и ручные перехваты идут вперёд)
  и раскладываются по времени — 6 клипов по 5 секунд.
- Ролик **переигрывается в реальном городе**: камера встаёт туда, откуда снимали (крыша, улица —
  но не в реке и не в лесу, и не за высоткой), цель идёт своим курсом, приходит перехватчик,
  город остаётся ночным независимо от времени суток.
- **Каждый клип снят по-разному** и два одинаковых подряд не идут: с балкона, с улицы (оператор
  ведёт телефон за целью), «прямо над нами» (цель проходит над головой), с видеорегистратора
  едущей машины, из окна и **с камеры самого перехватчика** — последнее только у ракет и дронов.
- Режиссура: ствольные бьют **очередью трассеров** (последние снаряды и попадают), ракета идёт
  **по дуге** с дымным шлейфом, FPV-дрон доворачивает змейкой. За долю секунды до попадания кадр
  уходит в **замедление ×3**, телефон дёргается и «отъезжает» на вспышке.
- Звук честный: **сначала свет, потом грохот** — взрыв и тряска приходят с задержкой на расстояние
  (340 м/с), гул «шахеда» слышно заранее, очередь доносится издалека.
- Вокруг — **вертикальный кадр телефона**: строка состояния, канал и «ПОДПИСКА», прогресс по
  клипам, ник автора с галочкой, подпись, которая печатается сама, лайки/комментарии/просмотры,
  живые комментарии горожан, строка «♪ оригинальный звук», зерно, виньетка и бегущая полоса.
  Клик по кадру — лайк с разлетающимися сердечками.
- Нарезка открывается **заставкой канала** и закрывается **итогами ночи** (ролики, лайки,
  просмотры, «завтра в это же время»); под неё играет ночная музыка.
- **Экспорт в файл**: кнопка «⤓ СОХРАНИТЬ ВИДЕО» во время показа или «⤓ Сохранить» в ленте —
  нарезка проигрывается один раз от начала и пишется в `Видео/UAD/<город>_cuts_dayN.avi`
  (540×960, 30 кадров/с, Motion JPEG + звук с шины мастера, то есть ровно то, что слышно).
  Кодировщик не нужен: контейнер AVI пишется сам (`scripts/core/avi.gd`), файл открывают VLC,
  проигрыватель Windows, ffmpeg и любой видеоредактор. В углу идёт счётчик «ЗАПИСЬ 42%»,
  Esc прерывает запись и недописанный файл удаляется, в конце показывается путь и кнопка
  «Открыть папку».
- Смотреть: кнопка **«▶ Нарезка ночи»** в утреннем отчёте или **T** → «Лента города» (архив по дням,
  хранится 20 последних ночей, сохраняется в мир). Пробел — следующий клип, Esc — закрыть.
- Пока идёт показ, **игра полностью заморожена**: часы, налёт и пожары стоят, время не идёт.

## Пожарная служба и разрушение домов

Попадание больше не просто «штраф и огонёк»: **дом физически теряет верхние этажи**.

- Коробка здания оседает (шахед — ~15 % высоты, крылатая — 25 %, баллистика — 35 %, обломки с БЧ — 10 %),
  скатная крыша обрушается, вниз сыплются **куски стен**, поднимается облако пыли.
- Полностью дом не складывается: ниже **45 % исходной высоты** он не оседает, сколько бы ни прилетало.
- Прогноз падения обломков, высоты крыш и столкновения дронов сразу считаются по новой, осевшей высоте.

На пожар выезжает **пожарно-спасательная служба** (депо стоит рядом с базой):

- 3 расчёта в городе бесплатно, ещё до 6 нанимается в магазине ($9 000 за расчёт).
- Машины с мигалками едут к ближайшему пожару, при необходимости **через мосты** (реку вброд никто не берёт),
  тушат его струёй воды и сразу уезжают на следующий; если проезда нет — возвращаются, и пожар выгорает сам.
- После тушения дом попадает в **очередь восстановления**: этажи отстраиваются обратно, копоть сходит,
  шкала «ГОРОД» растёт. Одновременно строится столько домов, сколько у вас расчётов.
- Утром служба берётся за всё, что осталось разрушенным после ночи.
- В шапке HUD видно: «🔥 Пожаров · расчётов · стройка», в утреннем отчёте — «Потушено пожаров · восстановлено зданий».
- Пожар, до которого никто не доехал, горит ~3.5 минуты и гаснет сам — дом остаётся осевшим до приезда бригад.

## Прогулка по городу (G)

Вид от первого лица: WASD — идти, Shift — бегом, Пробел — прыжок, мышь — осмотреться, G — назад.
Из вида сверху вы высаживаетесь там, куда смотрит камера. Здания непроходимы, по мостам можно
перейти Днепр, в реку зайти нельзя. На улицах ездят машины и ходят люди (ночью, во время тревоги,
большинство в укрытиях). Пока вы гуляете, ствольная ПВО работает в автоматическом режиме.
На телефоне: левая половина экрана — джойстик, правая — обзор.

## Управление и настройки

Все игровые клавиши переназначаются в **Настройки → УПРАВЛЕНИЕ**: нажмите на клавишу справа
и нажмите новую (Esc — отмена, «Сбросить управление» — вернуть по умолчанию). Занятая клавиша
автоматически освобождается у прежнего действия, привязки сохраняются в `settings.cfg` и
подставляются прямо в подписи кнопок и подсказки.

По умолчанию: **V** — вид, **G** — прогулка, **C** — пульт FPV, **Z / X** — соседняя ПВО,
**F** — автоогонь, **N** — ночной прицел, **H** — камера к базе, **B** — магазин, **T** — лента,
**Esc** — пауза, **Пробел / R** — в FPV следующий дрон и отправить на базу.

Не меняются (чтобы прицел и ходьба оставались предсказуемыми): движение **WASD / стрелки**,
мышь — прицел, **Shift** — бег и разгон, **1–9** — выбор ПВО, **Alt** — свободный курсор.

## Геймплей

- **Выбор позиции** на 3D-карте города: *Лес* (маскировка ×0.35, дальность стволов −30%), *Берег Днепра / реки / моря*
  (обломки падают в воду), *Город* (штрафы за крыши, база легко обнаруживается, награда +25%), *Поле*.
- **День**: разведчики «Орлан» ищут базу. Если найдут — ночью точный удар крылатыми/баллистическими ракетами.
- **Ночь**: сирена, рои «Шахедов», крылатые ракеты с манёврами, баллистика «Искандер-М» по дуге.
- **Физика обломков**: сбитая цель распадается на горящие обломки, которые сохраняют её инерцию (×0.75),
  падают с гравитацией и сопротивлением воздуха. Попадание на крышу — штраф и пожар; в воду/лес — без ущерба.
  Под целью под курсором рисуется **прогноз точки падения** (зелёный/синий — безопасно, красный — жилые дома).
- **Высоты**: цели идут разными эшелонами (шахеды — от 175 м между высотками до 1.6 км, куда пулемёт
  не достаёт), плавно меняют высоту; крылатые ракеты огибают крыши и делают «горку» перед ударом.
- **Промахи целей**: РЭБ сбивает с курса не только шахеды (24%), но и крылатые (18%) и баллистические
  ракеты (16%) — они падают в стороне от цели; подбитые, но не уничтоженные шахеды теряют управление.
  Попадание мимо цели дешевле прямого, но дом всё равно горит.
- **Промахи перехватчиков**: если ракета не попала, она подрывается рядом и осколками наносит цели часть
  урона (до 34 юнитов от точки подрыва), в журнале появляется «Промах: … в N м от цели», а в отчёте —
  строка «Промахи ракет». Повторный пуск по цели, которую уже добивают ракеты в полёте, не расходует
  боекомплект — система сообщает «ЦЕЛЬ УЖЕ ПЕРЕХВАЧЕНА».
- **Баллистика**: 90 HP и пологая траектория (15–22 с полёта). Patriot снимает одной ракетой,
  IRIS-T — двумя-тремя; стволы против неё по-прежнему бессильны.
- **Блэкаут**: попадание в ТЭЦ гасит свет в окнах, фонари и трафик района до утра.
- **Рой против роя**: «Шершень» дешевле ракеты в 2.5 раза и восполняется возвратом дронов, но летит
  175 км/ч — крылатую ракету он догоняет с трудом, а баллистику не достаёт вовсе.
- **Ночное свечение**: у двигателей шахедов, крылатых и баллистических ракет и у ракет-перехватчиков —
  светящиеся факелы и шлейфы, видимые на любой дальности.
- **Нарастание угрозы**: первые две ночи — только «Шахеды», крылатые ракеты с 3-й ночи, баллистика с 5-й
  (на сложности «Сложная» — с 4-й), высокие эшелоны вне досягаемости пулемёта — с 4-й. Размер волн,
  штрафы и доходы зависят от сложности (`GS.DIFFICULTY`: `enemies` / `penalty` / `income`).
- **Экономика**: награды за цели, госфинансирование каждое утро, бонус «чистое небо»; магазин — 12 комплексов ПВО
  четырёх классов, ракеты и дроны-перехватчики, маскировочная сеть, ремонт базы и кварталов, пожарные расчёты.
  Дрон стоит $700 и возвращается на базу, если не нашёл цель, — самое дешёвое средство против «Шахедов». За повреждённую крышу платят один раз,
  осколки того же обломка добавляют лишь четверть штрафа. Долг не заканчивает игру ночью: утром списывается
  до $20 000 «экстренной помощи». Поражение — разрушение базы, города или долг свыше $80 000 к утру.

## Тестовый режим

Любой билд (редактор или `UAD.exe`) принимает аргументы после `--`:

```bat
UAD.exe -- --autotest --loc=river --weapons=mg --day=1 --speed=6 --quit-at=26
UAD.exe -- --screen=map --shot=map.png --shot-at=3 --quit-at=4
UAD.exe -- --city=odesa --plan=odesa.png --plan-at=0,0,2000 --quit-at=1
```

`--city=kyiv|kharkiv|dnipro|odesa` — какой город загрузить (меню, карта, автотест); `--plan=file.png [--plan-at=x,z,size]` —
план города сверху (вода, зоны, трассы, здания, мосты, резервы) — работает и в `--headless`;
`--genprof` — время этапов генерации; `--switchtest` — мир другого города перестраивает карту.
`--mptest` — самотест мультиплеера без сети (коды, зеркало событий Firebase; с `--autotest` — друг в городе,
вид его глазами, список Tab, запрос на вход; с `--screen=worlds` — вкладка друзей с примерами);
`--mpid=КОД` — играть под другим кодом друга (вторая копия игры на том же компьютере).
`--mphost` / `--mpjoin=КОД` — живая сессия двух копий через настоящую базу: хост сам принимает
запрос, гость ставит базу рядом и стреляет, в конце обе печатают счёт, частоту и возраст снимков и
поправки кукол (`--mpholdfire` — хост не стреляет, все сбития — гостя); после теста игра убирает
свои записи из базы.
`--fakerelease=N` — притвориться, что в базе вышла сборка N (кнопка и окно обновления в меню).

**Кадры без окна.** `tools_scripts/shots.sh` запускает игру на отдельном скрытом рабочем столе
Windows (`hidden_run.ps1`): окно не появляется на экране и не забирает фокус, звук выключен,
3D-кадр рендерится во внеэкранный буфер 1920×1080. `--shot=file.png --shot-at=N` — один кадр,
`--shotlist=list.json` — несколько ракурсов за один запуск, `--shot-ui` (+ `SHOTS_WINDOW=1920x1080`)
— кадр вместе с интерфейсом.

`--view=fpv` — сразу за пультом дрона, `--fpv-at=N` — сесть за пульт на N-й секунде;
`--crush=X,Z` — обрушить и поджечь ближайший к точке дом (проверка пожарной службы), `--camat=X,Z[,D]` — навести камеру; `--view=base --aimbot --nv --nomarkers` — вид с базы с автонаведением; `--savetest` — проверка сохранений; `--keytest` — проверка назначаемых клавиш; `--avitest[=path]` и `--exporttest[=keep]` — запись видео (контейнер и весь тракт записи проверяются без окна, на сгенерированных кадрах).
`--autotest` запускает бой с умным автоогнём и печатает утренний отчёт/итог (`--loc=river|forest|city|field`,
`--weapons=mg,gepard,drone,iris,patriot`, `--day`, `--speed`, `--follow`, `--open=shop|pause|morning|gameover`).
