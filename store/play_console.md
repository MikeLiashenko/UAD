# Google Play Console — что куда вписывать

Шпаргалка для первой публикации UAD. Всё проверено по коду игры на 2026-10-20 (v1.3.18, build 40).

## 0. Перед первой загрузкой
1. **Копия ключа подписи.** Папка `%USERPROFILE%\.uad\` (`uad-release.keystore` + `signing.json`) —
   на флешку и в облако. Без неё не выпустить обновление.
2. **Сборка для Play:** `.\build.ps1 -Target aab` → `build\android\UAD.aab`.
   В ней (export feature `play`) игра не предлагает скачивать .apk с GitHub — обновления идут через Play.
   Каждая новая загрузка в Play должна иметь versionCode больше прошлой: просто собирай без `-NoBump`.
3. **Ключ подписи приложения (Play App Signing).** При создании выпуска Play спросит про ключ.
   Совет: выбрать «Использовать свой ключ» (Use a different key → Export and upload a key from
   Java keystore) и загрузить `uad-release.keystore` через инструмент PEPK, который Play даст скачать.
   Тогда версия из Play и .apk с GitHub подписаны одним ключом и ставятся друг поверх друга.
   Если оставить ключ Google по умолчанию, тем, кто ставил .apk с сайта, придётся удалить игру
   (миры экспортировать заранее: Играть → Экспорт мира) и поставить из Play заново.

## 9. Безопасность данных (Data safety)
- Собирает или передаёт данные пользователей? — **Да**
- Все данные шифруются при передаче? — **Да** (HTTPS)
- Можно запросить удаление данных? — **Да**
- Ссылка на удаление аккаунта: **https://mikeliashenko.github.io/UAD/privacy.html#delete**
- Можно ли удалять часть данных, не удаляя аккаунт? — **Нет** (удаляется аккаунт целиком)

Типы данных (отмечать только эти):

| Тип | Собирается | Передаётся третьим | Обязательно? | Зачем |
|---|---|---|---|---|
| Личная информация → **Адрес эл. почты** | да | нет | **необязательно** (только с аккаунтом) | Управление аккаунтом |
| Личная информация → **Идентификаторы пользователя** (ник, код друга) | да | нет | **необязательно** (только онлайн) | Функциональность приложения, управление аккаунтом |
| Активность в приложении → **Другие действия** (данные общей игры, статус в сети) | да | нет | необязательно | Функциональность приложения |

- Данные обрабатываются временно (эфемерно)? — для статуса и сессий — **да**; для аккаунта — **нет**.
- «Передаётся третьим» = **нет**: Firebase — это поставщик услуг (service provider), он
  по правилам Google не считается передачей.
- Не отмечать: местоположение, контакты, фото/видео (сохраняются только на устройстве),
  аудио, файлы, календарь, финансы, здоровье, история браузера, идентификаторы устройства,
  диагностика и сбои (в игре нет аналитики).

## 11. Страница в магазине
- Тексты: `store/listing.md` (uk / ru / en).
- Значок 512×512: `store/graphics/icon_512.png`
- Баннер 1024×500: `store/graphics/feature_1024x500.png`
- Скриншоты: `store/graphics/<uk|ru|en>/01_…08_*.jpg` — 1920×1080 JPEG, 8 штук на язык.
  Одни и те же файлы грузить в «Телефон», «Планшет 7"» и «Планшет 10"» (Play принимает 16:9,
  сторона от 1080 пикс.). Сняты так, как игра выглядит на Android: рендер Compatibility, лучшая
  графика для Android, сенсорное управление. Переснять: `bash tools_scripts/store_shots.sh [uk ru en] [-- сцена …]`.

## 12. Тестирование и выпуск
1. **Внутреннее тестирование** (до 100 человек, без проверки) — загрузить `UAD.aab`, поставить себе
   на планшет из Play, проверить, что игра запускается и мультиплеер работает.
2. **Закрытое тестирование: минимум 12 тестеров, 14 дней подряд** — обязательно для личных
   аккаунтов разработчика, созданных после ноября 2023. Тестеры — по списку Google-почт или через
   Google-группу; они должны принять приглашение по ссылке и держать игру установленной.
3. После 14 дней — **заявка на рабочую версию** (Apply for production): анкета о том, как прошло
   тестирование. Проверка обычно от нескольких дней до недели.
4. Можно выбрать **Ранний доступ** (Early access), раз игра в Alpha.

## 13. Риски проверки
- **Политика «чувствительные события»**: игры про идущую войну проверяют строже. Описание и
  скриншоты — про оборону и защиту городов; не использовать реальные фото, символику армий,
  призывы, названия реальных подразделений. Если отклонят — ответить через форму апелляции:
  игра об обороне городов, без насилия над людьми, без реальных съёмок.
- **Самообновление** уже убрано из Play-сборки (feature `play`). Не загружать в Play обычный .apk.
- Если Google попросит — ссылки на удаление аккаунта и политику должны открываться без входа.
